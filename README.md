🚑 RoadRescue 
RoadRescue is a robust web platform that bridges the gap between distressed vehicle owners and emergency service providers. It simplifies the process of finding and booking roadside assistance, ensuring help is just a few clicks away. The system provides a seamless experience for users to book services and for administrators/providers to manage requests.

🌟 Key Features:-
User & Provider Portals: Distinct dashboards for users to book services and providers/admins to manage requests.
Secure Authentication: robust login and registration system using JWT (JSON Web Tokens) with role-based access control (RBAC).
Service Booking System: Intuitive flow for users to select, book, and track emergency services.
Payment Integration: Secure online payments via Razorpay integration.
Responsive Design: Fully responsive UI built with React and Bootstrap, ensuring compatibility across mobile and desktop devices.
RESTful API: Scalable backend architecture documenting endpoints with OpenAPI/Swagger.

🛠️ Tech Stack:-

Frontend
Framework: React 19 (via Vite)
Styling: Bootstrap 5, React-Bootstrap
Routing: React Router DOM 7
State & Forms: Formik, Yup (Validation)
HTTP Client: Axios
Utilities: React Toastify (Notifications), jwt-decode, React Icons

Backend:-
Framework: Java 17, Spring Boot 3.2.4
Database: MySQL / MSSQL (Spring Data JPA)
Security: Spring Security, JWT
Payment Gateway: Razorpay
Tools: ModelMapper, Lombok, OpenAPI (Swagger)
